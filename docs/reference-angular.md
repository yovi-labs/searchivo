# Angular API reference

Import all symbols from `@searchivo/angular`. Declared peers are `@angular/core` 22.2.3 and `@searchivo/core` 0.1.0-rebuild.0. The application is tested with Angular common/compiler/platform-browser 22.2.3, RxJS 7.8.2, TypeScript 6.0.3 and Node 24.22.1. Read exact peers in the [package manifest](https://github.com/yovi-labs/searchivo/blob/develop/packages/angular/package.json); other combinations are unverified.

| Export                       | Parameters, return and defaults                                                                                                                                                                                                                            |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `createSearchivo<T>(source)` | Requires `SearchSource<T>`. Returns `{ provide(): Provider[]; inject(): Searchivo<T> }`. No global singleton, styles or debounce is installed.                                                                                                             |
| `SearchivoInput`             | `{ query: Signal<string>; setQuery(query: string): void }`; use as a native-input policy boundary.                                                                                                                                                         |
| `Searchivo<T>`               | Extends `SearchivoInput` with readonly `state: Signal<SearchState<T>>` and `controller: SearchController<T>`. `setQuery` starts a query-only search.                                                                                                       |
| `SEARCHIVO_INPUT`            | `InjectionToken<SearchivoInput>` consumed by the directive; defaults to the handle via a `useExisting` provider. Override within the same scope to add debounce/refinements.                                                                               |
| `SearchivoInputDirective`    | Standalone selector `input[searchivo]`. Imports native input/composition handling and a Signal effect. Public `composing` tracks IME; `onInput(InputEvent)` and `onCompositionEnd()` implement host events. Consumers normally interact through the input. |

`provide()` creates a new typed token scope each time the binding is constructed, with independent controller instances per injector. `inject()` must run within injection context and find that binding's providers. Scope cleanup uses Angular `DestroyRef`. It does not dispose an external shared Worker/HTTP resource; the consumer must own its transport cleanup.

The [Angular recipe](angular.md) is a complete minimal example. The [live feature lab](https://searchivo.netlify.app/#features) and [source](https://github.com/yovi-labs/searchivo/blob/develop/apps/angular-example/src/features.ts) demonstrate overriding input policy, matching control scope, readonly Signals and asynchronous sources. Missing directive imports, missing providers, calling inject outside context, and expecting `setQuery` to retain previous filters are common integration mistakes. See the [interaction reference](reference-interaction.md) for error/cancellation behavior.
