# R-ADR-009: Validated HTTP source

The optional adapters package POSTs typed portable SearchRequest JSON to an explicit HTTP(S) endpoint. It validates unknown result IDs, finite scores, documents via caller guard, totals, facet counts/allowlisted fields and optional object metadata before returning typed values. Duplicate result IDs reject. A backend may return additional metadata but cannot bypass the document guard.

The adapter races fetch/body validation against a separate cancellation/timeout promise. AbortController informs cooperative transports; the race also rejects noncooperative ones. Finally removes the external abort listener and clears timeout. The generation-aware core controller remains responsible for preventing older requests from replacing newer state. Cancellation does not stop a backend's already-running search.

This is a source adapter, not a distributed search server. Authentication/credentials and response mapping are supplied through a custom fetch wrapper or a backend endpoint. No implicit credential collection or provider lock-in is introduced.
