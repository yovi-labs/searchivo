# Public package inventory

The package manifests define availability; source helpers without a manifest entry point are not public imports. The website generates declaration sections and an export-name inventory directly from **every** manifest export, including types. Changes to a manifest therefore change the reference automatically. [Exact generated declarations](https://searchivo.netlify.app/api/).

There are no root imports for workers/themes and no public `@searchivo/core/tokenize` entry point. Import `tokenize` from the core root. Do not import `src`, `dist`, internal worker protocol helpers or built Angular implementation paths from applications. Optional modules remain explicit and are checked by package-boundary and installed-tarball tests.
