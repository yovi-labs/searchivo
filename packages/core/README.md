# @searchivo/core

Zero runtime dependencies. A typed local inverted index with atomic mutations, ranking and optional search features.

`tokenize` applies NFKC, locale-independent lowercase and Unicode letter/number/mark splitting. Accents are retained. Punctuation and emoji separate terms. No stemming or language-specific segmentation is promised.

## Installation and reference

Install in your application:

```sh
npm install @searchivo/core@0.1.0
```

See [installation and release availability](https://searchivo.netlify.app/docs/tutorial/).
